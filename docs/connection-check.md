# 연결·입력·퇴장 검증 기록

검증일: 2026-09-27

범위: `NEXT_STEPS.md` 3단계. localhost의 Node.js 24, 실제 Colyseus SDK, Chromium·WebKit을 사용했다. 실제 모바일 기기·네트워크 전환·외부 HTTPS/WSS 검증은 포함하지 않는다.

## 발견한 문제와 수정

- SDK 0.18.4는 자동 복귀 콜백 이후 재접속 토큰을 갱신했다. 콜백 안에서 토큰을 저장하던 흐름을 제거하고, 새 Room 연결이 완료된 뒤 갱신된 토큰을 저장한다. 복귀 직후 새로고침으로 같은 방에 돌아오는 것을 확인했다.
- SDK의 예약 재시도는 퇴장으로 취소되지 않았고 입장 후 5초 이내에는 자동 복귀를 시도하지 않았다. SDK 자동 재시도를 끄고 `useGame`이 복구 시도와 타이머를 관리한다. 입장 직후의 연결 종료도 복구하며, 복구 중에는 중복 입장·수동 복귀·입찰을 차단한다.
- 취소한 입장·복구 요청이 늦게 완료되면 이전 방으로 돌아갈 수 있었다. 요청마다 세대를 구분해 이전 응답을 버리고 그 Room에서 퇴장한다. 입장 중에는 연결 취소 버튼을 제공한다.
- 복귀 실패 뒤 이전 화면과 토큰이 남았다. 만료·방 소멸·최종 연결 종료 시 스냅샷, 개인 미션, 반응, 세션 토큰과 주소의 방 코드를 정리하고, 한국어 사유와 함께 새 입장 화면으로 돌아간다.
- 복구 제한은 처음 연결이 끊긴 시점부터 30초다. 새 소켓이 열려도 최신 공개 상태와 본인 상태를 모두 받기 전에는 복구 완료로 처리하지 않는다. 동기화 전에 다시 끊겨도 최초 마감을 유지한다.
- 재경기 때 다른 참가자의 오류와 반응이 남을 수 있었다. 대기실 전환 시 정리하고, 새 방·새 미션에서는 비밀 미션을 닫는다. 이전 방의 지연된 클립보드 완료도 새 방의 복사 안내를 바꾸지 못하게 했다.

반복 실행하는 소켓 테스트는 서버 내부 설정으로 재접속 유예를 2초로 줄였다. 방 생성 payload의 `reconnectionSeconds: 0`은 무시되며, 클라이언트는 유예를 변경할 수 없다. 브라우저의 최초 복구 마감 검사는 브라우저 시계만 이동시키고 실제 서버 시계는 유지한다. 390px 연결 취소 화면에서 가로 넘침이 없음을 확인했다.

브라우저 종료 안내 테스트는 실제 WebSocket에 서버 종료 코드 4001을 주입한다. 프로세스 재시작 자체는 아래 별도 SDK 실측으로 확인했다. 브라우저의 지연 응답 검사는 실제 HTTP·WebSocket 응답을 보류했다가 전달하며 제품 코드에 테스트 전용 경로를 추가하지 않는다.

재실행 명령:

```sh
npm run typecheck
npm test
npm run test:e2e
npm run test:dev
npm run format:check
```

이번 환경의 브라우저는 `/private/tmp/oddbid-playwright`에 설치했다. 해당 설치를 재사용하면 브라우저 명령 앞에 `PLAYWRIGHT_BROWSERS_PATH=/private/tmp/oddbid-playwright`를 지정한다. 다른 환경에서는 `npx playwright install chromium webkit`으로 설치한다.

## 기본 30초와 실제 서버 재시작 실측

자동화의 짧은 유예와 별도로, `reconnectionSeconds`를 지정하지 않은 서버 프로세스에서 확인했다. 경매 시간만 10초, 낙찰 공개는 100ms로 설정했다.

1. 3인 경매에서 방장이 15코인을 입찰한 뒤 연결을 종료했다.
2. 종료 후 28,036ms까지 방장 권한과 좌석이 유지됐다.
3. 30,011ms에 남은 참가자에게 권한이 넘어갔고 이전 토큰으로의 복귀가 거절됐다.
4. 연결 종료 전에 수락된 입찰은 끊긴 동안 정상 정산되어 잔액 85코인·물건 1개로 유지됐다.
5. 서버 프로세스를 강제 종료하고 같은 포트에서 새 프로세스를 시작했다. 이전 토큰과 방 참가 요청은 거절됐고, 새 3인 경매와 10코인 입찰은 성공했다.

측정값은 이번 로컬 실행의 관찰값이며 운영 환경의 지연 보장은 아니다. 원시 세션 토큰과 비밀 미션은 기록에 포함하지 않는다. 실행에 사용한 임시 스크립트는 Git 제외 경로인 `work/socket-boundary-check.ts`, `work/socket-boundary-server.ts`에 있으며 정규 회귀 테스트는 `tests/`에 유지한다.
